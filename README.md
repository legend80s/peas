# Peas

<div align="center">
  <img src="https://koboyo.com/icons/svg/pea-pod.svg" width="30%" />
</div>

> A pseudo mono repo for utils only run in Node.js.

It is just a shell—like a pea pod—for shared `devDependencies` (TypeScript, Biome, [npm-shipwright](https://www.npmjs.com/package/npm-shipwright), etc.) and shared files (.gitignore, .npmrc, etc.) across the packages in `./packages/**`.

## Notice

- This repo should not be published. Only `./packages/**` can be published.
